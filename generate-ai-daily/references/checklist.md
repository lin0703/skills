# AI日报检查清单

## 触发场景

当用户要求“生成 AI 日报 / 做报纸风 AI 新闻图 / 修日报版式 / 去掉模板味”时使用。

## 生产前

- 确认新闻内容不是站点旧示例残留
- 先整理成结构化 JSON
- 主标题必须是当天核心结论，不要直接写 `AI日报`

## 渲染前

- `paper_name` 可保留 `AI日报`
- `title` 必须是具体头条
- `highlights` 不超过 5 条
- `sections` 控制在 2-4 个
- `footer_note` 用中文

## 渲染后

逐项检查：

1. 顶部是否出现两行 `AI日报`
2. 右侧是否还写着 `TL;DR`
3. 页脚是否还写着 `Mobile Brief`
4. 是否残留英文模板语
5. 是否适合在飞书聊天窗口直接看
6. 是否适合转发到小红书

## 常见修复

### 问题：顶部重复“AI日报”

原因：`paper_name` 和 `title` 都写成 `AI日报`

修复：
- 保留 `paper_name = AI日报`
- 把 `title` 改成当天真正主标题

### 问题：右侧有 TL;DR

原因：模板残留英文区块标题

修复：改成 `重点速览`

### 问题：页脚有 Mobile Brief

原因：模板残留英文角标

修复：改成 `特别整理` 或别的中文角标

### 问题：用户说“我要在聊天窗口看到图片，不要文件”

修复：直接发送图片消息，不只给下载链接
