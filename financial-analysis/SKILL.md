# 财务分析技能

## 工作流

1. 先拿到已经按季度聚合好的查询结果；如果还没有结果，就先走 `sql-query` 技能。
2. 多季度走势使用 `trend_analysis`。
3. 去年同期比较使用 `yoy_compare`。
4. 当前 demo 的环比使用 `mom_compare`，口径为上一季度。
5. 需要展示时再调用 `render_chart` 和 `render_table`。

## Demo 边界

- 所有比较都保持季度粒度。
- 不扩展月度或年度逻辑。
- 如果历史数据不够，不要编造分析，要明确说明“数据不足”。

## 输出风格

- 先说当前季度和对比季度，再给变化百分比。
- 结论尽量短，优先用“上升/下降/持平”加一个关键数字。
- 趋势默认折线图，季度对比默认柱状图。
