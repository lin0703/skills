# 点金术方法补充

## 1. 先排雷，后买点

点金术的核心不是抓最惨，而是排除价值毁灭。

先解释下跌原因，再判断是否进入候选池。技术信号只能做确认，不能替代基本面判断。

## 2. 阶梯建仓的底层逻辑

阶梯建仓不是无限补仓。

它只适用于：
- 公司没有明显基本面塌陷
- 下跌更多来自情绪、周期、错杀或短期波动扩张
- 可以用历史真实波动测出相对合理的分层距离

如果标的进入基本面恶化或爆雷范畴，应立即停止机械补仓框架。

## 3. 两种阵型的直觉区别

### 1-2-3-4
适合大多数正常波动股票。
优点是越跌越重，均价下得更快。
缺点是首仓轻，若股价不给深回撤，容易买不够。

### 3-2-2-3
适合低波核心资产。
优点是更早建立底仓，不容易踏空长期慢牛型资产。
缺点是如果误判成低波白马，首仓会偏重。

## 4. 使用建议

- 普通标的默认 1-2-3-4
- 真正低波核心资产才考虑 3-2-2-3
- 任何阵型都要绑定失效条件
- 跌破最后一层后，不继续自动补仓，必须回到基本面复核
