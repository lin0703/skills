# 异常检测技能

## 工作流

1. 先确认当前季度值已经拿到。
2. 准备至少 4 个历史季度点，优先使用最近 8 个季度。
3. 调用 `anomaly_detect`，传入当前值和历史基线序列。
4. 返回偏离比例、基线均值，以及是否超过阈值。

## Demo 边界

- 基线只使用季度数据。
- 默认阈值是 30%，除非用户明确指定其他阈值。
- 如果历史样本太少，就返回“样本不足”，不要强行判异常。

## 输出风格

- 第一段先明确是否异常。
- 带上基线均值和偏离百分比。
- 如果未异常，要说明当前值仍处于最近季度的正常波动范围内。
